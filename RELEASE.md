# Release Checklist

Use this checklist when publishing Phrase Selects to GitHub or sharing an installer file.

## Before Packaging

1. Set the new version everywhere it appears (manifest, package.json, `src/version.js`, and `index.html`):

```bash
npm run set-version -- 1.0.0
```

2. Add a matching entry to `CHANGELOG.md`.
3. Build the package folder. This runs `npm run check` first and fails on version drift, leftover debug labels, syntax errors, or failing tests:

```bash
npm run build
```

4. Run the manual Premiere smoke checklist in `README.md`.

## Package The Installer

Adobe distributes UXP plugins as `.ccx` files. Use UXP Developer Tool to create the installer:

1. Open UXP Developer Tool.
2. Choose Add Plugin and select `dist/manifest.json` (not the project folder's manifest, which would package tests, scripts, docs, and `.git`). If Phrase Selects is already listed from the project folder, remove it first, because both entries share the same plugin ID.
3. Open the plugin action menu for the `dist/` entry.
4. Choose Package.
5. Select a local output folder.
6. Double-click the generated `.ccx` and install locally through Creative Cloud.
7. Test the installed plugin in Premiere before uploading it anywhere.

Do not rename a source zip to `.ccx`; let UXP Developer Tool build the installer package.

After packaging, you can remove the `dist/` entry from UXP Developer Tool and re-add the project folder for day-to-day development with Load & Watch.

## GitHub Release

1. Commit the release changes and create a tag that matches the manifest version, such as `v1.0.0`.
2. Create a GitHub Release from that tag.
3. Attach the `.ccx` file generated by UXP Developer Tool.
4. Include the supported Premiere version from `manifest.json`.
5. Include a short note that local installs show Adobe's unverified-plugin warning until the plugin is submitted through Adobe's distribution process.
